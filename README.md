## 📱 Mobile-First Features

- **Responsive Header & Drawer Menu:** Mobile-friendly rendering of the official logo, contact shortcuts, and structured drawer navigation.
- **Fixed Mobile Sticky Bar:** 3 touch-friendly action buttons (Call Now, WhatsApp, Book Ride) that stay visible without obscuring screen content.
- **Floating WhatsApp:** Expand-on-hover luxury WhatsApp launcher for desktop and tablet users.
- **Zero Layout Shifts:** High performance, responsive image rendering and smooth scrolling.

---

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 with custom `@theme` brand tokens
- **Routing:** React Router v7 (`react-router-dom`)
- **Icons:** Lucide React
- **SEO & Structured Data:** Semantic HTML5, Schema.org `TaxiService` JSON-LD, XML Sitemap (`/sitemap.xml`), and `robots.txt`.

## 💻 Development & Build Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
# Server runs at http://localhost:5173/

# Run production build
npm run build
# Generates optimized output in ./dist

# Preview production build
npm run preview
```
